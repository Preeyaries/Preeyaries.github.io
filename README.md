# Preeyaries.github.io

Personal website of Preeyanan (Ploy) Khamfoei, hosted with GitHub Pages.

- Live site: https://preeyaries.github.io
- Resume: https://preeyaries.github.io/resume/
- Design file: Figma, "Preeyanan Personal Website"

## Structure

```
index.html              Home: hero, role circle, links to other pages
student/index.html      Me as a Com Sci Student
designer/index.html     Me as a Web designer
artist/index.html       Me as an Artist
traveller/index.html    Me as a Traveller
hobby/index.html        My hobbies
profile/index.html      My profile and social media
game/index.html         Mini game
resume/index.html       Online resume with a Download PDF button
assets/css/style.css    Shared styles for every page
assets/js/site.js       Role colours and cartoon avatars (shared)
assets/js/dial.js       Role circle on the home page
assets/js/game.js       Mini game logic
```

To edit a page, open its index.html. To change colours or fonts for the whole site, edit assets/css/style.css.

## How to update

1. Edit the files (or replace them with a new version).
2. In GitHub Desktop: write a short summary, click **Commit to main**, then **Push origin**.
3. GitHub Pages redeploys automatically in 1 to 2 minutes.
